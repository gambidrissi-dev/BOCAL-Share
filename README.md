# Bocal

Télécharge et range les vidéos (YouTube, Vimeo…) pour la base média Cobalt.

**[Télécharger la dernière version](https://github.com/gambidrissi-dev/BOCAL-Share/releases/latest/download/Bocal.zip)** · macOS 14.0 ou plus récent

Ce dépôt ne contient pas de code : il distribue Bocal. L'app se met à jour toute seule
par [Sparkle](https://sparkle-project.org) depuis [`appcast.xml`](appcast.xml), et chaque archive est signée (EdDSA).

Toutes les apps, et **Vitrine** pour les installer d'un clic : https://apps-gambi.vercel.app/
